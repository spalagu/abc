# Demo 验收说明

## 概述：验证什么，怎样算通过

| 验证 | 怎么做 | 符合预期 |
|---|---|---|
| 原工作接入 | Mac 打开草稿，手机选择这个现有窗口 | 同一份草稿，没有创建第二个应用实例 |
| 断线接续 | 手机修改无风险草稿，关网页再扫码 | 内容仍在，Host 应用和任务没退出 |
| 文字控件 | 读取一次，尝试写入一个测试输入框 | 原控件更新；不支持时明确提示，不伪造成功 |
| 画面流量 | 手动连续取两次静态画面，然后静置 | 第二次通常只有元数据/少量变化块；不主动刷新时不传画面 |
| 真实场景 | 接入 Host 内网页面和已有 Codex 会话 | 能继续原现场；语义不足时用原画面核对和操作 |
| 问题定位 | 导出无内容诊断 | 得到不含密钥、文字、图像的 JSON |

先同一自家 Wi-Fi 验证。它不等于已经验证了蜂窝网络、VPN或所有应用兼容性。不要用删除、付款、生产环境、自动审批来做初测。

## 安装和连接

1. 从 Releases 下载 Apple 芯片 `arm64` 或 Intel `x86_64` ZIP，而不是自动生成的 Source code.zip。解压，将 WorkContinuity.app 放进“应用程序”。预编译版内置 Python。
2. 应用只有 ad-hoc 签名，未做 Apple 公证。核对自己的仓库、构建和校验和后，按 macOS 对此应用的正常确认流程打开；不关闭系统安全功能。若无法打开，可使用后面的源码方式。
3. 点击 Host 的“请求辅助功能与屏幕录制权限”，在系统设置授权实际出现的 WorkContinuity。退出重开。源码模式可能显示 Terminal/Python，取决于启动方式。
4. Mac 与手机连同一个可信 Wi-Fi，勾选“允许可信局域网连接”，确认 HTTP 风险，点“启动服务”。若系统询问本地网络/防火墙，按你的可信网络策略允许应用。
5. 手机相机扫码。网页选择 Mac 已打开的窗口。先读取文字，再刷新原画面。
6. 需要操作时点“取得控制权”和“将目标窗口置前”。只有勾选“允许点画面操作”，点图才发送真实点击。文本输入不会自动按回车。

HTTP 是明文。不得把 8765 端口转发到公网，不在公共 Wi-Fi 使用。连接地址中的密钥等同控制权限，不要分享二维码或日志。

## 详细操作

### A. 无风险草稿

Mac 打开 TextEdit，新建纯文本写 `host-before`，暂不保存。手机选择该窗口，点“读取一次”。若找到可写文本控件，将内容改成 `phone-after` 后点“写入原控件”。这会替换该控件全文，不会自动提交。

若没有可写控件，使用原画面：取得控制、置前、刷新、允许点击，点文本区域，再发送测试文字。关掉手机网页，重新扫码接入并选择原窗口。

通过：草稿仍在，内容正确，没有第二份 TextEdit。语义读不到本身是需要记录的兼容性结果，不代表应用没内容。

### B. 内网站点

Mac 现有浏览器打开你自己的内网站点。手机接入对应窗口，读一段文字、操作无破坏性的搜索或导航。必要时使用原画面。

通过：操作发生在 Host 原网页、原登录状态。此版不是网络代理，网站仍在 Host 渲染；远端传文字控件或按需画面。

### C. Codex

Mac 先打开一个已有、无风险的测试对话。手机选择相应窗口，读取文字；缺失时查看原画面。在原会话发送“仅回复一句文字，不修改文件”，检查结果是否仍属于这个会话。

通过：接续原对话，不启动另一套 Codex。记录文字是否完整、输入能否成功、什么步骤需要原画面。此版没有 Codex 私有 API 适配；不承诺所有 Electron 控件都能通过 AX 读取。没有自动审批。

### D. 流量

刷新统计记录起点。同一静态窗口取两次画面，然后放置 30 秒，不勾选“每 3 秒刷新”。没有请求时画面预算不增加；第二次一般只有少量元数据。闪烁光标、时间戳、动画会造成真实变化块。

完成一次工作后导出诊断。统计是 HTTP 正文，不包括请求头、TCP/TLS、重传和 VPN，不是运营商计费流量。默认 5 MiB 是所有客户端共享的画面响应正文预算，不是总网络流量硬上限。预算耗尽后画面暂停，手动文字读取仍可用。开发者可用 `--budget-mib 0.05` 快速验证暂停。

### E. 防误操作

读取画面后，在 Mac 移动或切换窗口，再从手机点旧画面。预期拒绝旧输入，提示变化或目标不在前台。超过 30 秒的画面需要刷新，文字快照操作有效期为 60 秒。关闭目标窗口后报窗口已离开，不自动切到别的窗口。

控制租约 120 秒，每次操作续期。一个访问端控制时，另一个不能抢占；可主动释放。传输超时不自动重试，先检查原窗口是否已经执行。

## 路上测试（可选）

本 demo 不自建中继，不自动装 VPN，不更改路由器。你可使用自己的私有 HTTPS/VPN。例如 Mac 和手机登录同一 Tailscale tailnet，在 Mac 明确运行：

```bash
tailscale serve --bg http://127.0.0.1:8765
```

将返回的 HTTPS origin 填入 Host 的“可选 HTTPS 代理地址”，取消局域网明文选项，启动后扫新二维码。手机打开 Tailscale，改用蜂窝网络测试。后端继续只监听 127.0.0.1。

不要使用公开发布的 Funnel；不要执行 `serve reset` 清掉其他服务。CLI 不在 PATH 时按你所安装的 Tailscale 发行版文档操作。这些是配置步骤，尚未在你的实际 tailnet 验证。

Host 必须在线、未锁屏且未睡眠；本版不自动解锁、不绕过权限、不修改睡眠设置。停止 demo 即撤销本轮密钥，已有工作仍继续。

## 故障与备用启动

窗口列表空/无标题：检查屏幕录制权限、当前桌面、窗口未最小化。某些安全内容不允许捕获。

AX 对应不唯一：同一应用多个同名窗口可能无法识别。先用单一测试窗口，或在 Mac 手动置前后用原画面；不会偷偷读取另一个窗口代替。

手机连不上：确认扫码地址不是 127.0.0.1；两端同网、非访客隔离网络、防火墙允许。更新应用后可能需要重新授权，从固定“应用程序”路径启动。

源码备用需 Python 3.11+，双击 `Start-Mac.command`。它只在项目内建立 .venv 并装固定依赖，不需要 sudo。终端会显示启动错误。
