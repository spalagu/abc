# Demo 0.1.2 验收说明

## 先验证权限入口

Host 顶部应显示 `0.1.2-demo`。辅助功能与录屏是两行独立按钮：“请求权限”只请求该行权限，“打开…设置”只打开对应页面。不要再反复点旧的合并请求按钮。

**录屏列表没有应用：**在“录屏与系统录音”上方列表点“＋”，选择当前运行的 WorkContinuity.app 并开启。不是下面的“仅系统录音”。新 Host 显示实际应用路径，并可在 Finder 定位。完整退出重开 Demo 后，点“重新检查授权”，再重新配对查看画面。旧版也可以用“＋”手动添加，无需先更新或再次重置全部权限。

通过标准：两个设置入口不混淆、请求不连弹两种权限、授权重开后当前进程查询与实际读取/截图一致。快捷跳转受 macOS 版本影响；若页面不对，按“系统设置 → 隐私与安全性 → 对应权限”手动进入。

仍为 ad-hoc 签名；本版不承诺更新后无需重新授权，不自动授予权限。详细说明见 [PERMISSIONS.md](PERMISSIONS.md)。

## 输入回归（保留 0.1.1 修复）

更新 Host 应用并重新打开连接，页面顶部应显示 `0.1.2-demo`。**无需点“手动置前”。** 选择原窗口 → 取得控制权 → 刷新画面 → 勾选“允许点画面操作”。

| 验证 | 操作 | 通过标准 |
|---|---|---|
| 右键处理 | 在画面内右击 | 不再弹浏览器菜单；画面旁说明操作结果或拒绝原因 |
| 左键处理 | 点击无风险按钮 | Host 原按钮被操作，或明确提示后台能力不足；不再无反馈 |
| 后台优先 | 保持浏览器在前台操作目标应用 | Demo 不主动激活/置前目标，默认走后台控件 |
| 手机右键 | “点击按钮”选“右键”，再点画面 | 只发送一个右键动作，不同时触发左键 |
| 只读恢复 | 取消允许操作，再右击画面 | 不发送 Host 操作，恢复浏览器菜单 |

默认“后台控件”使用应用声明的 AXPress / AXShowMenu 能力。应用没有提供时会明确报错，不偷偷改发全局点击。可在无风险窗口显式选择“后台定向键鼠（实验）”：它检查目标进程及其 AXFocusedWindow，再向进程投递，不主动置前。但系统没有应用执行回执，应用也可能忽略事件或自行改变焦点，**“已提交”不等于“执行成功”**。前台兼容方式只是独立可选项，仍要求目标已经在前台。

右键菜单可能是独立窗口，单窗口截图未必包含。因此“拦截本地浏览器菜单”“Host 接受右键”“远端看到并操作目标菜单”是三个验收项；最后一项尚未保证。不要因为画面没变就盲目重复可能已执行的操作。

## 安装和连接

1. 在 Releases 下载 Apple 芯片 `arm64` 或 Intel `x86_64` ZIP，而非 Source code.zip。退出旧 WorkContinuity，解压后替换“应用程序”内的应用。Python 已打包。
2. 应用仅 ad-hoc 签名，未做 Apple 公证。核对自己的仓库、构建和校验和后，按 macOS 对此应用的正常确认流程打开，不关闭整体系统安全检查。
3. 分别按 Host 两行的“请求权限”，授权并处理完一项后再操作另一项。打开设置页本身不会授权。列表没有应用时用“＋”添加 Host 显示的当前 WorkContinuity.app。授权后完整退出重开。源码模式以系统提示中的启动终端/Python 为准。
4. 同一可信 Wi-Fi 下，明确开启“允许可信局域网连接”，确认 HTTP 风险并启动，手机扫描新二维码。不要把 8765 映射到公网，不在公共 Wi-Fi 使用。
5. 选择已有窗口、取得控制权、刷新并允许画面操作。新密钥代替旧密钥；停止 Host 会撤销密钥，但不退出目标应用。

## 核心工作接续

先用 TextEdit 无风险未保存草稿，不用删除、付款、生产系统或自动审批做初测。Mac 输入 `host-before`，远端读一次文字；有可写控件时改为 `phone-after` 并写入原控件（替换全文，不自动提交）。再关网页、重新扫码接入，草稿应仍在，没有第二份应用。

接着验证 Host 已打开的内网页面，进行无破坏性的阅读/搜索；操作仍发生在 Host 原网页、原登录状态。本版不是浏览器网络代理。

最后接入现有 Codex 测试对话，发送“仅回复一句文字，不修改文件”，检查仍是原对话。记录哪些内容可语义读取、哪些操作需要图像或定向实验模式。没有 Codex 私有 API 适配，不保证所有应用控件完整。

## 流量与防误操作

记录统计起点，对静态窗口连续取两次画面，再静置 30 秒且不启用自动刷新。第二次通常少量元数据/变化块；不请求时画面预算不增加。光标、时间戳和动画会造成真实变化。默认 5 MiB 是 Host 所有客户端共享的画面正文预算，不是总网络计费上限；HTTP 头、TCP/TLS、重传、VPN、其他接口另算。

移动目标窗口后点旧画面应被拒绝。仅改变前台不应阻止后台控件方式；前台兼容方式仍会拒绝非前台目标。画面动作有效期 30 秒、文字快照 60 秒；过期需刷新后重新判断。控制租约 120 秒，操作续期。忙碌中额外点击明确拒绝，不排队、不自动重放。

## 路上测试（可选）

本 demo 不自建中继，不自动安装 VPN 或更改路由器。可用自有私有 HTTPS/VPN。例如两端登录同一 Tailscale tailnet，Mac 明确运行：

```bash
tailscale serve --bg http://127.0.0.1:8765
```

将返回的 HTTPS origin 填入 Host 的可选代理地址，取消局域网明文模式，启动并重新扫码。手机启用 Tailscale 后用蜂窝网络测试。后端仍只监听本机。不要使用公开 Funnel；不要运行 `serve reset` 清掉其他服务。命令不在 PATH 时按所安装发行版的官方说明处理。这里是配置说明，不代表已在你的 tailnet 验证。

Host 需在线、未锁屏且未睡眠。程序不会解锁、绕过权限或更改睡眠设置。
